# Christoffel's Private Chef – Menu Manager

## Project Description
Christoffel's Private Chef is a menu management application that allows the user to manage food items on a menu. The application was developed using React Native and Expo.

The aim of the application is to make it easier to add, update, remove and find menu items, while also displaying useful menu statistics.

## Features Added in Part 3

### 1. Managing Menu Items
- Added the ability to edit existing menu items.
- Added the ability to delete menu items.
- Updated the save function so that changes are displayed immediately.
- Added confirmation before deleting a menu item.

### 2. Search and Filtering
- Added a search bar to find menu items by their names.
- Added filters for Starter, Main Course and Dessert.
- Added a clear option to reset the search and filters.
- Added a message when no matching menu items are found.

### 3. Menu Statistics
- Added a total count of all menu items.
- Added a calculation for the average menu price.
- Added a count of items in each course category.
- Statistics update automatically when menu items are added or deleted.

### 4. Improvements to the Application
- Improved the layout and appearance of the application.
- Used reusable functions to manage menu items.
- Improved input validation to prevent incomplete or incorrect information.
- Added feedback messages when menu items are added, updated or deleted.
- Improved the organisation of the code and styling.

## How to Run the Application
1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run `npm install`.
5. Run `npm start`.
6. Press `w` to open the application in a web browser.
